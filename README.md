MovieMate

About:

MovieMate is an Android movie application that allows users to register, log in, search for movies, view movie information, create a watchlist and rate movies.

Features:

- User registration
- User login
- Movie search
- Movie details
- Watchlist
- Movie ratings
- Settings
- Logout

Technologies:

- Kotlin
- Android Studio
- Jetpack Compose
- Firebase Authentication
- Firebase Firestore
- Node.js
- Express
- Retrofit
- JUnit
- GitHub

REST API:

The MovieMate REST API is created using Node.js and Express.

The API provides movie search, movie details, watchlist and rating functionality.

Testing:

Automated unit tests are included in the Android project.

Database:

Firebase Firestore is used to store movie, watchlist and rating information.

Authentication:

Firebase Authentication is used for user registration and login.

GitHub Actions:

GitHub Actions is used to run automated tests.
